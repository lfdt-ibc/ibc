# Specification Template

This file is the specification template of the Community Specification framework. The IBC specifications use their own template instead: start a new specification from [ics-template.md](ics-template.md), follow the format set by [ICS 1](ics-001-ics-standard/README.md), and take it through the stages in [PROCESS.md](PROCESS.md).

The upstream Community Specification Template is available at [github.com/CommunitySpecification/Community_Specification](https://github.com/CommunitySpecification/Community_Specification/blob/main/07-spec-template.md).
